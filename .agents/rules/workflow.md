# Regras de Fluxo de Trabalho do Usuário

Sempre que o usuário for iniciar, clonar ou realizar alterações em um repositório, você DEVE fornecer o passo a passo claro contendo:
1. **Como configurar e rodar o ambiente inicial** (clonagem, instalação de dependências `npm install`, inicialização do servidor `npm run dev` ou scripts batch).
2. **Como salvar e enviar as alterações** (comandos `git add .`, `git commit -m "..."`, `git push origin main` com boas práticas de commit).
